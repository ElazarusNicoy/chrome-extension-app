# Nike Basketball Shoes Search Extension

A simple Chrome extension that automates searching for "nike basketball shoes - mid top" on Google.

## What is this for?

This extension is designed to quickly perform a specific Google search for Nike basketball shoes with mid-top style. It's useful for users who frequently need to search for this particular item, automating the repetitive task of opening Google and typing the query.

## Features

- Automatically opens a new tab with Google search results for "nike basketball shoes - mid top" when the extension popup is opened.
- Built with Manifest V3 for modern Chrome extension standards.
- Compatible with Chromium-based browsers (Chrome, Brave, Microsoft Edge).

## Installation

1. Download or clone this repository.
2. Open your browser (Chrome, Brave, or Edge).
3. Go to the extensions page:
   - Chrome: `chrome://extensions/`
   - Brave: `brave://extensions/`
   - Edge: `edge://extensions/`
4. Enable "Developer mode" (toggle in the top right).
5. Click "Load unpacked" and select the folder containing this extension's files.
6. The extension should now appear in your toolbar.

## Usage

1. Click the extension icon in your browser toolbar.
2. The popup will briefly appear, and a new tab will automatically open with the Google search results for "nike basketball shoes - mid top".

## Permissions

- **tabs**: Required to open new tabs with the search results.

## Development

To modify the search query, edit the URL in `popup.js`.
